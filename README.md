# Edexcel Maths Tutor

A revision tutor for Pearson Edexcel A level Mathematics:

- **Pure Mathematics Year 2, Chapter 7:** Trigonometry and modelling
- **Statistics & Mechanics Year 2, Chapter 5:** Forces and friction

Each section has notes, a worked example, and exam-style questions with hints, a mark scheme and a full solution. The AI tutor solves your own questions (typed or photographed) step by step, marks your working and writes similar questions to practise.

## Switching on the AI

The AI features use your own Anthropic API key. Open **Settings** on the site and paste the key. It is stored only in your browser and sent only to `api.anthropic.com`. It is never stored in this repository.

## Hosting

The whole app is the single file `index.html`, served by GitHub Pages from the `main` branch.
